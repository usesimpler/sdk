# Security policy

## Reporting a vulnerability

Report a vulnerability privately through GitHub private vulnerability reporting:

[Open a private security advisory](https://github.com/usesimpler/sdk/security/advisories/new)

Do not open a public issue, pull request, or discussion for a suspected vulnerability, and do not include exploit details in any public place.

Include the package name, the version you tested, and what an attacker can do. We will acknowledge the report and coordinate a fix through the advisory.
