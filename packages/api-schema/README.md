# `@usesimpler/api-schema`

The **Integrator schema package**: Zod schemas and OpenAPI registration for the **Integrator API surface**.

`@usesimpler/sdk-core` depends on this package. Integrators install the client, not this package.

The public OpenAPI document generated from these schemas is [`openapi/public-openapi.json`](../../openapi/public-openapi.json).

## Support window

While the API is on 0.x, the current and previous minor are supported. A deprecation notice is published before a minor is dropped. After 1.0, each major is supported for at least 12 months.
