# Changelog

`@usesimpler/api-schema` and `@usesimpler/sdk-core` version in lockstep. Each package also gets a changelog when Changesets publishes a release.

## Support window

While the API is on 0.x, the current and previous minor are supported. A changelog deprecation notice is published before a minor is dropped. After 1.0, each major is supported for at least 12 months.

## Deprecations

Dropped support for 0.0. The 0.0.0 publish is not an integrator release. The oldest supported version is 0.1.0.
